# MIRA Operator - Dependencies and System Requirements

## Toolchain & Runtime
- Rust: >= 1.75.0 (Edition 2021)
- Cargo: >= 1.75.0
- Windows: MSVC C++ Build Tools or MinGW GCC (MSVCRT runtime)
- Linux (optional): build-essential, libx11-dev, libxrandr-dev
